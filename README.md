# Book Royalty & Profit ROI Calculator

---

## Omni-Code 25.0 — Book Royalty & Profit ROI Calculator 📊

An interactive, browser-based financial model and ROI calculator designed for independent authors, tech founders and self-publishers in Kenya. This tool provides real-time unit economics, break-even analysis and revenue projections for both physical print runs and direct digital (M-Pesa/e-book) sales.

## 🚀 Overview

Publishing a hybrid tech-biography/memoir requires balancing pre-press fixed costs, print production expenses, retailer commissions and direct-to-consumer digital distribution. 

This single-file web application calculates:
* **Hardcopy & Softcopy Unit Net Margins** after accounting for printing, payment gateways and retailer commissions.
* **Total Project Outlay & Gross Revenue** across dual-track distribution channels.
* **Hardcopy Break-Even Analysis** to determine the exact number of physical units required to cover fixed production costs.
* **Return on Investment (ROI)** percentage based on customizable sales volumes.

---

## ⚡ Features

* **Zero Dependencies:** Built with pure HTML5, vanilla JavaScript, and utility-first styling via Tailwind CSS CDN. No framework overhead, npm packages or build steps required.
* **Dynamic Real-Time Calculation:** Automatically updates financial metrics on user input change.
* **Tailored for the Kenyan Publishing Ecosystem:** Pre-configured with local baseline figures (KES currency, KNLS/KECOBO compliance costs, M-Pesa gateway fees, local retail bookstore commissions).
* **Responsive Dark Dashboard UI:** Designed with a clean, high-contrast UI suitable for desktop and mobile screens.
